# Flame Fractal IFS Affine Transform Draw

Renders flame fractals using an Iterated Function System with multiple affine transformations. Millions of random points are plotted into a density histogram, then tone-mapped with gamma correction to produce the characteristic HDR glow effect on a dark canvas. Four presets (Fern, Sierpinski, Dragon, Flame) and a randomizer are included.

## Features

- Histogram-based density rendering with logarithmic tone mapping and gamma correction
- Four named presets: Barnsley Fern, Sierpinski Triangle, Dragon Curve, Flame
- Random preset generator for endless unique fractals
- Adjustable iterations per frame, brightness, gamma, and color cycle hue
- Editable affine transform coefficients (a, b, c, d, e, f) for each function
